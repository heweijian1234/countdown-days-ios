## 3. 撞到什么坑（新坑清单，待主窗验证回填 SKILL.md 地雷表）

1. **🔴误填事故（已修复）**：第一轮注入用"祖先链 innerText 含'版权'"匹配字段，因页面文本字段相邻（关键词→…→版本→版权），祖先链爬到 6 层时版权两字混入关键词框的匹配 → **"2026 He Weijian" 被写进了 en-US 关键词框且保存落库**。已从 `asc_填料.py` 找回原 keywords，API PATCH 恢复，回读确认无损。**教训：注入类操作字段定位必须先验证唯一性再写入（本次改用"版本框 value=1.0 的右邻 input"精确定位）。**
2. **ASC 版本页表单注入不认（版权卡住的根因）**：native setter + input/change/keyup 事件全家桶能改 DOM 显示值，但 React 内部 state 不认 → **保存按钮恒 disabled**。对照实验：对"技术支持网址"字段用 CDP 真实键入（trusted events）删字补字，保存按钮同样不亮 → **整个版本页对脚本注入免疫**，不是版权框特殊。唯一一次保存成功（第 1 轮）是错位注入关键词框时恰好触发了那个框的 onChange。
3. **ego CDP page 级 ws URL 缺端口**：`/json/new` 返回 `ws://localhost/devtools/page/...`（**没有 :9336**），直连必拒；必须替换为 `ws://127.0.0.1:9336/devtools/page/...`。`/json/version` 的 browser 级 URL 反而正常带端口。
4. **playwright connectOverCDP 对 ego 挂死**：Python 和 Node 版都在 "ws connected" 后超时（browser-level ws 兼容问题）→ ego 自动化只能用**裸 websockets 页面级 ws**（H 母版 `asc_网页重提.py` 路线）。
5. **websockets 15.x 移除 suppress_origin**：母版里的 `suppress_origin=True` 会 TypeError（H 时代 websockets 旧版可用）。实测 15.0.1 下**不带此参数页面级 ws 也能连**（配合坑 4 的端口修正）。
6. **ASC 是 React 16**：事件处理器 key 为 `__reactEventHandlers$`（17+ 才是 `__reactProps$`）；另有 jQuery 混用。直调 onChange 实测也没能让保存按钮变亮。
7. **ASC 网页私有 API = iris**：`appstoreconnect.apple.com/iris/v1/...`（页面内 fetch 带登录态可调，已抓到 `appStoreReviewDetails`/`timeZones` 端点；**版本详情端点没抓到**，是版权字段没走完的路）。
